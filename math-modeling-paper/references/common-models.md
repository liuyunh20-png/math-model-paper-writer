> 按 7 大问题类型分类，涵盖 17 篇优秀论文中出现的所有模型方法。

## 模型选择决策树

```
问题是什么类型？
│
├── 需要评价/排序 → 评价模型
│   ├── 层次分析法 (AHP)
│   ├── TOPSIS
│   ├── 灰色关联分析
│   ├── VIKOR
│   └── 模糊综合评价
│
├── 需要预测未来 → 预测模型
│   ├── 时间序列 (ARIMA)
│   ├── Prophet
│   ├── LSTM
│   ├── 灰色预测 (GM)
│   ├── VAR (多变量时间序列)
│   └── 回归分析
│
├── 需要最优化 → 优化模型
│   ├── 线性规划
│   ├── 非线性规划
│   ├── 整数规划
│   ├── 多目标优化 (NSGA-II)
│   └── 智能算法 (模拟退火/遗传算法/粒子群)
│
├── 需要分类/聚类 → 分类聚类模型
│   ├── K-means / K-means++
│   ├── 层次聚类
│   ├── 贝叶斯分类
│   └── SVM
│
├── 需要找关联 → 关联分析
│   ├── 相关性分析 (Pearson/Spearman)
│   ├── FP-Growth 关联规则
│   └── 灰色关联分析
│
├── 需要分析关系 → 统计建模
│   ├── 回归分析 (线性/非线性)
│   ├── 贝叶斯模型
│   ├── 方差分析
│   └── 假设检验
│
└── 需要刻画特征 → 数据挖掘
    ├── RFM/RFMS/RFMT 模型
    ├── 用户画像
    └── 描述性统计
```

## 一、评价模型

### 层次分析法 (AHP)

| 项目 | 内容 |
|------|------|
| **适用场景** | 多准则决策、方案排序、权重确定 |
| **优点** | 简单直观，适合定性定量结合 |
| **缺点** | 主观性强，一致性检验可能不通过 |
| **优秀论文实例** | 2017C论文1：用 AHP 分析数据量和颜色维度对模型的影响因子 |
| **关键步骤** | 1.建立层次结构 → 2.构造判断矩阵 → 3.一致性检验 → 4.计算权重 |
| **软件工具** | MATLAB (`eig`函数), Python, Excel |

### TOPSIS

| 项目 | 内容 |
|------|------|
| **适用场景** | 多方案多指标的综合评价排序 |
| **优点** | 客观，充分利用数据信息 |
| **缺点** | 对权重敏感，需要合理确定权重 |
| **关键步骤** | 1.标准化矩阵 → 2.确定正负理想解 → 3.计算贴近度 → 4.排序 |

### 灰色关联分析

| 项目 | 内容 |
|------|------|
| **适用场景** | 分析各因素对目标的影响程度 |
| **优点** | 样本量要求低，计算简单 |
| **缺点** | 只能反映序列形状的相似性 |
| **优秀论文实例** | 2023C-C050：分析季度蔬菜丰富度、节日因素对销量的关联度 |
| **关键步骤** | 1.确定母序列和子序列 → 2.数据标准化 → 3.计算关联系数 → 4.计算关联度 |

### VIKOR

| 项目 | 内容 |
|------|------|
| **适用场景** | 多准则决策，特别适合冲突准则的折中 |
| **优点** | 考虑最大化群体效用和最小化个体遗憾 |
| **优秀论文实例** | 2023C-C228：用于蔬菜补货决策评价 |

## 二、预测模型

### ARIMA (自回归积分滑动平均模型)

| 项目 | 内容 |
|------|------|
| **适用场景** | 单变量时间序列预测 |
| **优点** | 理论成熟，适合短期预测 |
| **缺点** | 需要平稳性，不适合非线性数据 |
| **优秀论文实例** | 2023C-C235：蔬菜销量预测 |
| **关键步骤** | 1.平稳性检验 → 2.定阶 (ACF/PACF) → 3.参数估计 → 4.模型检验 → 5.预测 |
| **软件工具** | R (`forecast`包), Python (`statsmodels`) |

### Prophet

| 项目 | 内容 |
|------|------|
| **适用场景** | 具有季节性和趋势的时间序列预测 |
| **优点** | 自动处理季节性、节假日效应，无需太多调参 |
| **缺点** | 对突发波动预测能力弱 |
| **优秀论文实例** | 2023C-C235：蔬菜补货和定价模型 |
| **软件工具** | Python (`prophet`库) |

### LSTM (长短期记忆网络)

| 项目 | 内容 |
|------|------|
| **适用场景** | 复杂非线性时间序列预测 |
| **优点** | 能捕捉长期依赖关系，适合多变量预测 |
| **缺点** | 需要大量数据，训练时间长 |
| **优秀论文实例** | 2023C-C228：蔬菜成本和销量预测 |
| **关键步骤** | 1.数据归一化 → 2.构建序列 → 3.网络设计 → 4.训练 → 5.预测 → 6.反归一化 |
| **软件工具** | Python (PyTorch/TensorFlow) |

### VAR (向量自回归模型)

| 项目 | 内容 |
|------|------|
| **适用场景** | 多变量时间序列的联合预测和关系分析 |
| **优点** | 能同时预测多个相关变量 |
| **缺点** | 参数较多，需要大样本 |
| **优秀论文实例** | 2023C-C126：蔬菜销量和补货量联合预测 |
| **关键步骤** | 1.平稳性检验 → 2.定阶 (AIC/BIC) → 3.参数估计 → 4.模型检验 → 5.预测 |

### 贝叶斯模型

| 项目 | 内容 |
|------|------|
| **适用场景** | 小样本统计推断，不确定性量化 |
| **优点** | 能融合先验信息，量化不确定性 |
| **缺点** | 先验选择主观，计算复杂 |
| **优秀论文实例** | 2023C-C126：Bayesian 销量模型，使用 WinBUGS/BUGS 进行 MCMC 求解 |
| **关键步骤** | 1.模型设定 → 2.先验分布选择 → 3.MCMC采样 → 4.收敛性检验 → 5.后验估计 |

## 三、优化模型

### 线性规划

| 项目 | 内容 |
|------|------|
| **适用场景** | 目标函数和约束均为线性的优化问题 |
| **优点** | 理论成熟，求解高效 |
| **优秀论文实例** | 2023C-C050：蔬菜补货定价优化 |
| **标准形式** | `max/min z = c'x  s.t. Ax ≤ b, x ≥ 0` |
| **软件工具** | MATLAB (`linprog`), Python (`scipy.optimize.linprog`) |

### 非线性规划

| 项目 | 内容 |
|------|------|
| **适用场景** | 目标函数或约束含非线性项 |
| **优秀论文实例** | 2023C-C228：混合非线性双目标优化模型 |
| **软件工具** | MATLAB (`fmincon`), Python (`scipy.optimize`) |

### 多目标优化 (NSGA-II)

| 项目 | 内容 |
|------|------|
| **适用场景** | 多个冲突目标的优化问题 |
| **优点** | 能找到 Pareto 最优前沿 |
| **优秀论文实例** | 2023C-C228：使用 NSGA-II 求解蔬菜补货和定价的双目标优化 |
| **软件工具** | Python (`pymoo`), MATLAB |

## 四、分类聚类模型

### K-means / K-means++

| 项目 | 内容 |
|------|------|
| **适用场景** | 无监督聚类 |
| **优点** | 算法简单，效率高 |
| **缺点** | 需预设簇数，对异常值敏感，对初始点敏感 |

| **关键步骤** | 1.选择K → 2.初始化中心 → 3.分配样本 → 4.更新中心 → 5.迭代 |
| **软件工具** | Python (`sklearn.cluster.KMeans`), R (`kmeans`) |

|------|------|
| **适用场景** | 有监督分类 |

## 五、关联分析

| 项目 | 内容 |
|------|------|

## 模型选择建议

### 按数据特征选择

| 数据特征 | 推荐模型 |
|----------|----------|
| 小样本 | 灰色预测、贝叶斯模型 |
| 大样本 | LSTM、深度学习 |
| 非正态分布 | Spearman相关、贝叶斯模型、非参数检验 |
| 零膨胀数据 | 同期平均法 + 贝叶斯模型 |
| 时间序列 | ARIMA/Prophet/LSTM/VAR |
| 多变量联合 | VAR、多元回归 |

### 按问题目标选择

| 问题目标 | 推荐模型 |
|----------|----------|
| 排序/评价 | AHP/TOPSIS/VIKOR/灰色关联 |
| 预测 | ARIMA/Prophet/LSTM/回归 |
| 优化 | 线性规划/模拟退火/遗传算法/NSGA-II |
| 分类 | K-means/贝叶斯/SVM |
| 关联分析 | Pearson/Spearman/FP-Growth |

### 模型组合策略

优秀论文通常组合使用多个模型：

1. **统计分析 + 优化模型**：先分析数据规律，再建立优化模型（2023C-C050）
2. **预测 + 优化**：先用时间序列预测，再优化决策（2023C-C235）
3. **聚类 + 评价**：先聚类分类，再对各类别评价（2018C）
4. **关联分析 + 优化**：先分析关联关系，再优化策略（2023C-C228）
