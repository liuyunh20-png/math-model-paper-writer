# 数学建模竞赛论文写作指导

## Overview

本技能基于对 2017C、2018C、2019C、2020C、2023C 共 17 篇全国大学生数学建模竞赛国家一等奖优秀论文的深度结构分析，提炼出标准化的论文写作框架和各章节写作方法论。技能提供完整的论文结构指导、常用模型选择参考、逐章节写作技巧、优秀论文案例分析，以及可直接填充使用的论文模板。

## 核心框架：十段式标准结构

所有优秀论文均遵循以下结构（各部分缺一不可）：

```
标题
├── 摘要 + 关键词          （~5%，决定第一印象）
├── 一、问题重述            （~5%，用自己的话复述题目）
├── 二、问题分析            （~10%，逐问题分析思路 + 总体思路图）
├── 三、模型假设            （~3%，3-7条假设，每条附理由）
├── 四、符号说明            （~2%，表格列出全部符号）
├── 五、模型建立与求解       （~60%，核心部分，按问题逐一展开）
│   ├── 数据预处理
│   ├── 问题一：建模→求解→结果分析
│   ├── 问题二：建模→求解→结果分析
│   ├── 问题三：建模→求解→结果分析
│   └── 问题四：建模→求解→结果分析
├── 六、模型评价与推广       （~5%，优点+缺点+改进+推广）
├── 参考文献                （~2%，4-10篇，规范格式）
└── 附录                    （~8%，代码+补充图表+支撑材料）
```

## 使用流程

### 场景一：从零开始撰写论文

1. 加载 `references/paper-structure.md` 了解各章节详细要求
2. 加载 `references/writing-tips.md` 获取逐章节写作技巧
3. 使用 `assets/paper-template.md` 作为起始模板
4. 根据问题类型，参考 `references/common-models.md` 选择合适的数学模型
5. 按"摘要→问题重述→问题分析→模型假设→符号说明→模型建立与求解→模型评价→参考文献→附录"顺序逐节完成
6. 最后回头精修摘要（摘要是最重要的部分）

### 场景二：审查/改进已有论文

1. 加载 `references/paper-structure.md` 作为检查清单
2. 逐节对照检查是否缺失关键内容
3. 加载 `references/writing-tips.md` 检查各部分写作质量
4. 参考 `references/excellent-paper-cases.md` 中优秀论文的写法进行对比改进

### 场景三：选择数学模型

1. 加载 `references/common-models.md`
2. 根据问题类型（评价/预测/优化/分类/关联）查找合适模型
3. 参考模型适用场景和优缺点进行选择

## 关键写作原则

1. **摘要优先级最高**：评委首先阅读摘要，需在半页到一页内完整概述全文。每个问题用一段话概括「方法 + 模型 + 结论」，附具体数值结果
2. **问题分析须有思路图**：用流程图展示全文逻辑框架，所有 2023 年优秀论文均包含此图
3. **公式全部编号**：如 `(1)`, `(2)`，便于后文引用
4. **图文并茂**：关键结果必须用表格和图形展示
5. **结果需要分析**：不仅展示数字，还要解释结果的合理性和现实意义
6. **评价要客观**：优点和缺点都要写，体现批判性思维
7. **代码放附录**：正文保持简洁，完整代码移至附录
