# 数模优秀论文标题模式库

## 一、高频标题公式

### 模式 A：基于[方法]的[对象][关键词]（最常见，占比约 50%）
这是国赛优秀论文中最主流的标题写法，简洁明了，直接展示核心方法与应用场景。

**结构**：`基于 + [核心算法/模型名称] + 的 + [研究对象] + [研究角度/目标]`

**真实示例**：
- 基于优化算法的农作物最优种植模型
- 基于遗传算法的最优种植策略
- 基于成分数据的古代玻璃制品的成分分析与鉴别
- 基于价格弹性的蔬菜类商品自动定价与补货决策
- 基于梯度下降的决策树算法与非线性规划的信贷风险评估与信贷策略模型
- 基于优化算法的企业原材料订购与运输规划模型
- 基于双层和随机规划的原材料订购与运输问题
- 基于随机优化的农作物种植策略模型

**使用要点**：
- [方法]部分选全文最具代表性的 1-2 个核心方法
- [对象]部分用正式学术语言，避免口语化
- [关键词]部分用"模型""策略""方案""分析""研究"等学术名词收尾

### 模式 B：[方法]与[方法]下的[对象]方案/模型
当论文使用了两种以上的重要方法时适用。

**结构**：`[方法A] + 与/和 + [方法B] + （条件）下的 + [对象] + 方案/模型`

**真实示例**：
- 双目标贪心优化下的企业原料订购运输方案

**变体**：可将方法放在"基于"框架内，如"基于梯度下降的决策树算法与非线性规划的……"

### 模式 C：[对象]综合决策及[对象]管理模型
适用于多角度研究同一对象的论文。

**结构**：`[研究对象] + 综合决策/分析 + 及 + [管理/安排角度] + 模型`

**真实示例**：
- 机场出租车司机综合决策及机场出租车管理模型

### 模式 D：简洁叙事型
直接陈述研究内容，不使用"基于"前缀。

**结构**：`[针对/关于] + [对象] + 的 + [研究内容]`

**真实示例**：
- 针对中小微企业最优信贷决策研究
- 银行对中小微企业的信贷决策分析
- 商超蔬菜销售数据的统计分析及建模

## 二、标题长度规律

- **最佳长度**：15-30 个汉字
- **过短的标题**（<12字）显得空泛，如"机场的出租车问题"（19_C_03）明显不如同届其他标题专业
- **过长的标题**（>35字）信息过载，可考虑用副标题拆分

## 三、标题用词规范

### 推荐用词
| 类别 | 推荐词 | 避免词 |
|------|--------|--------|
| 模型类 | 模型、决策模型、优化模型 | 做法办法 |
| 方法类 | 策略、方案、分析、研究 | 做法、办法 |
| 修饰类 | 综合、最优、动态、多目标 | 很好的、优秀的 |
| 算法类 | 直接用算法英文名（遗传算法、模拟退火等） | 自己起的中文名 |

### 核心算法中英文对照
| 中文 | 英文 | 标题中推荐用法 |
|------|------|----------------|
| 遗传算法 | Genetic Algorithm | 遗传算法 |
| 模拟退火 | Simulated Annealing | 模拟退火 |
| 粒子群优化 | PSO | PSO算法 / 粒子群算法 |
| 蒙特卡洛 | Monte Carlo | 蒙特卡洛 |
| 决策树 | Decision Tree | 决策树 |
| 聚类分析 | Clustering | 聚类分析 |
| 回归分析 | Regression | 回归分析 |
| 层次分析 | AHP | 层次分析法 |
| 灰色关联 | Grey Relational | 灰色关联分析 |
| 随机规划 | Stochastic Programming | 随机规划 |
| 多目标规划 | Multi-objective Programming | 多目标规划 |

## 四、标题生成决策树

```
论文核心方法数量？
├── 1个核心方法 → 模式A：基于[方法]的[对象][关键词]
├── 2个核心方法 → 模式B：基于[方法A]与[方法B]的[对象][关键词]
└── 多角度研究 → 模式C：[对象]综合决策及[管理角度]模型
```

选择标题模式时，优先考虑：
1. 方法是否具有创新性或组合特色（有→用模式B）
2. 研究是否覆盖多个维度（是→用模式C）
3. 默认使用模式A
