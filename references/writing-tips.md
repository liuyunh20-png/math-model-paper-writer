# 逐章节写作技巧

> 基于 17 篇优秀论文的写作经验总结，针对每个关键部分提供具体方法和避坑指南。

---

## 一、摘要写作技巧

### 核心原则

摘要是论文最重要的部分，评委首先阅读摘要来决定是否继续细看全文。

### 写作公式

```
第一段（总述）：
本文是对 [研究问题] 的研究，通过 [核心方法]，建立了 [模型名称]，
给出了 [主要结论]。

第二段（问题一）：
针对问题一，首先 [方法/步骤]，建立了 [模型名称]，
[关键参数/指标]，得出 [主要结果，含具体数值]。

第三段（问题二）：
针对问题二，首先 [方法/步骤]，建立了 [模型名称]，
[关键参数/指标]，得出 [主要结果，含具体数值]。

...（每个问题一段）

最后一段：
最后本文对所建立的模型进行了讨论和分析，综合评价了模型的优缺点。

关键词：关键词1；关键词2；关键词3；关键词4；关键词5
```

### 关键要点

1. **用数据说话**：每个问题的结果都要给出具体数值
   - ✅ 「求解出未来一周最大收益为 5105.60 元」
   - ❌ 「求解出了最大收益」

2. **方法+模型+结论三要素**：每段必须包含
   - 方法：用了什么算法/方法
   - 模型：建立了什么模型
   - 结论：得到了什么结果

3. **关键词选择**：3-5 个，选择论文中核心使用的方法和模型名
   - 示例：「K-means++聚类；优化模型；模拟退火模型；灰色关联分析」

4. **篇幅控制**：半页到一页（300-800字）

5. **最后写摘要**：全文完成后回头写摘要，确保与正文一致

## 二、问题分析写作技巧

### 核心原则

问题分析是展示「思维过程」的部分，要说明「为什么用这个方法」，而不仅仅是「用了什么方法」。

### 写作结构

每个问题的分析包含三个层次：

1. **问题本质**：这个问要求做什么
2. **方法选择**：为什么选择这个方法（对比其他方法的优劣）
3. **求解路径**：具体的步骤流程

### 关键技巧

#### 1. 必须画总体思路图

所有 2023 年优秀论文都包含总体思路图。用流程图展示：
- 各问题之间的逻辑关系
- 数据流向
- 方法选择路径

#### 2. 体现问题递进关系

```
问题二是在问题一的基础上...
本题基于问题二构建的模拟退火模型...
```

#### 3. 方法选择的理由

```
❌ 差：「本文使用 K-means 聚类」
✅ 好：「考虑到数据量纲差距较大，本文使用 K-means++ 算法，
       该算法通过优化初始中心点选择，避免了 K-means 对初始值敏感的问题」
```

## 三、模型建立与求解写作技巧

### 核心原则

这是论文的核心部分（占 60%+），要做到：公式规范、图文并茂、逻辑清晰、分析到位。

### 子结构模板

每个问题的建模求解按以下结构：

```
5.X.1 [模型名称]
    ├── 模型原理（公式推导）
    └── 模型建立（数学表达式）

5.X.2 模型求解
    ├── 算法描述（流程图）
    └── 软件实现

5.X.3 结果与分析
    ├── 结果展示（表格+图形）
    ├── 结果解释
    └── 模型检验（可选）
```

### 关键技巧

#### 1. 公式全部编号

所有公式都要编号，如 `(1)`, `(2)`, `(3)`，便于后文引用：「如式 (5) 所示」「将式 (3) 代入式 (7) 得」

#### 2. 优化模型的标准写法

```
目标函数：
    max Z = ...        (1)

约束条件：
    s.t.  约束1        (2)
          约束2        (3)

其中：Z 为目标值，决策变量为 ...
```

#### 3. 结果展示要图文并茂

| 图表类型 | 适用场景 |
|----------|----------|
| 表格 | 展示精确数值 |
| 折线图 | 时间序列趋势 |
| 柱状图 | 分类对比 |
| 散点图 | 变量关系 |
| 饼图 | 占比分布 |
| 热力图 | 相关系数矩阵 |
| 流程图 | 算法步骤 |

#### 4. 结果分析不能省

```
❌ 差：仅展示结果表格
✅ 好：展示结果 + 分析原因 + 解释合理性

示例：
「由表 5 可知，花叶类蔬菜日销售量波动性较大，这是因为花叶类蔬菜
受季节影响显著，且保质期短导致供需波动剧烈...」
```

#### 5. 算法描述用流程图

复杂算法必须配流程图展示步骤。

#### 6. 数据预处理独立成节

2023 年优秀论文都将数据预处理独立成节，包括：缺失值处理、异常值剔除、数据标准化、描述性统计、数据可视化。

## 四、模型评价写作技巧

### 核心原则

客观评价，既要有优点也要有缺点，体现批判性思维。

### 优点写作模板

```
6.1 模型的优点
1. [准确性]：模型基于全部数据信息建立，具有较高的准确性...
2. [通用性]：模型具有通用性，能适用于不同场景...
3. [效率性]：算法效率高，求解速度快...
4. [实用性]：与实际紧密结合，具有现实指导意义...
```

### 缺点写作模板

```
6.2 模型的不足
1. [因素缺失]：某些因素未考虑，影响了模型精度...
   如：未考虑替代品与互补品价格变动的影响
2. [数据限制]：数据量有限，模型泛化能力有待验证...
3. [假设理想化]：某些假设过于理想化...
   如：将蔬菜销量与定价作为线性关系处理，忽略了边际效应
```

### 改进方向写作模板

```
6.3 模型的改进
1. 针对 [缺点1]，可引入 [更先进的方法] 进行改进...
2. 针对 [缺点2]，可在获取更多数据后 [改进方案]...
```

### 推广写作模板

```
6.4 模型的推广
本文建立的 [模型名称] 可推广到 [领域1]、[领域2] 等领域。
例如：可将 RFMT 模型推广到 APP 运营、通信行业用户分析等研究中。
```

## 五、参考文献写作技巧

### 格式规范

```
期刊论文 [J]：
[1] 作者. 文章名[J]. 期刊名, 年份, 卷(期): 页码.

书籍 [M]：
[2] 作者. 书名[M]. 出版地: 出版社, 年份.

学位论文 [D]：
[3] 作者. 论文名[D]. 学校, 年份.

网络资源：
[4] 资源名. URL, 访问日期.
```

### 注意事项

1. 引用数量 4-10 篇
2. 包含学术文献（期刊、书籍）和权威网络资源
3. 格式统一规范
4. 按正文引用顺序编号
5. 推荐引用数学建模经典教材：姜启源《数学模型》

## 六、附录写作技巧

### 代码附录

```
附录1 问题一代码
# 功能：[代码功能说明]
# 输入：[输入数据]
# 输出：[输出结果]
[代码内容]
```

### 支撑材料列表

```
附录N 支撑材料文件列表
文件名          类型          简介
data_clean.py   Python代码    数据清洗代码
model.py        Python代码    模型实现代码
result.xlsx     数据文件      求解结果
```

### 注意事项

1. 代码按问题顺序排列
2. 每段代码注明功能
3. 正文中因篇幅限制未展示的完整结果可放附录
4. 附录代码不需要全部展示，选关键部分即可

## 七、常见避坑指南

### 1. 摘要常见问题

| 问题 | 正确做法 |
|------|----------|
| 没有具体数值 | 每个问题都给出关键数值结果 |
| 方法描述太笼统 | 具体说明用了什么模型/算法 |
| 篇幅过长或过短 | 控制在半页到一页 |
| 关键词不当 | 选择核心方法和模型名称 |

### 2. 问题分析常见问题

| 问题 | 正确做法 |
|------|----------|
| 缺少总体思路图 | 必须画流程图展示全文逻辑 |
| 方法选择无理由 | 说明为什么选这个方法 |
| 问题间无关联 | 体现问题递进关系 |

### 3. 建模求解常见问题

| 问题 | 正确做法 |
|------|----------|
| 公式未编号 | 所有公式编号 |
| 只有表格无图形 | 图文并茂 |
| 结果无分析 | 解释结果合理性和现实意义 |
| 无数据预处理 | 独立成节描述数据清洗 |

### 4. 模型评价常见问题

| 问题 | 正确做法 |
|------|----------|
| 只写优点不写缺点 | 优缺点都要写 |
| 缺点太笼统 | 具体说明哪里不足及原因 |
| 无推广 | 说明可推广到哪些领域 |
