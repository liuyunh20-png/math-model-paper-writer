## 二、图片类型分类

### 2.1 统计图表类（出现频率最高）

| 图类型 | 出现频率 | 典型用途 | 代表实例 |
|--------|----------|----------|----------|
| **柱状图** | 极高 | 分类对比、结果展示 | 蔬菜损耗率、品类销量对比 |
| **折线图** | 极高 | 时间序列、趋势分析 | 12季度销量、三年销量曲线 |
| **饼图** | 高 | 占比分布 | 品种丰富度、性别比例 |
| **散点图** | 高 | 变量关系、相关性 | 价格-销量关系、浓度-颜色读数 |
| **直方图** | 中 | 数据分布 | 打折次数分布、销量分布 |
| **箱线图** | 中 | 分布特征、异常值 | 日销量箱线图、季节误差 |
| **热力图** | 中 | 相关系数矩阵 | 品类销量相关系数热力图 |

### 2.2 模型分析类

| 图类型 | 出现频率 | 典型用途 | 代表实例 |
|--------|----------|----------|----------|
| **流程图** | 高 | 总体思路、算法步骤 | 总体思路图（2023C标配） |
| **预测对比图** | 高 | 预测值vs真实值 | ARIMA/Prophet/LSTM预测 |
| **残差图** | 中 | 模型检验 | 回归残差图 |
| **收敛曲线** | 中 | 优化算法求解 | 模拟退火/遗传算法收敛 |
| **ACF/PACF图** | 中 | 时间序列定阶 | 自相关函数、偏自相关函数 |
| **时序分解图** | 低 | 趋势-季节分解 | STL分解、年时间序列分解 |
| **核密度图** | 低 | 参数后验分布 | Bayesian模型MCMC链 |
| **轨迹图** | 低 | MCMC收敛诊断 | Bayesian动态轨迹图 |

### 2.3 检验类

| 图类型 | 出现频率 | 典型用途 | 代表实例 |
|--------|----------|----------|----------|
| **鲁棒性检验图** | 低（2023C新增） | 模型稳定性 | LSTM微小扰动测试 |
| **K-S检验图** | 低 | 分布检验 | 月销量样本检验 |
| **Q-Q图** | 低 | 正态性检验 | 残差正态性 |

### 4.3 趋势

2023年论文相比早期论文：
- 图片绝对数量增长 2-3 倍
- 图片类型更加丰富（新增鲁棒性检验、核密度图、轨迹图等）
- 总体思路图成为标配
- 数据可视化更加专业（热力图、箱线图等高级图表增多）

## 五、图片标题规范

### 5.1 编号规则

- 图按全文统一编号：图1, 图2, 图3, ...
- 表按全文统一编号：表1, 表2, 表3, ...
- 不按问题分开编号

### 5.2 标题格式

**图标题**（置于图下方）：

```
图1 六大品类蔬菜的品种丰富度占比图
```

**表标题**（置于表上方）：

```
表1 符号说明
```

### 5.3 正文引用规范

```
如图1所示，花叶类蔬菜占品种数量的40%...
由表3可知，各指标与销量具有强相关性...
图2展示了数据预处理前后的对比效果。
将图5中的预测结果代入式(7)...
```

## 六、图片制作工具建议

| 图类型 | 推荐工具 |
|--------|----------|
| 柱状图/折线图/饼图 | Excel, Python(matplotlib), R(ggplot2) |
| 散点图/热力图 | Python(seaborn), R |
| 箱线图 | Python(matplotlib), R |
| 流程图 | Visio, draw.io, PowerPoint |
| 预测图/残差图 | Python, R(forecast), MATLAB |
| 时序分解图 | R, Python(statsmodels) |
| 核密度图/轨迹图 | R, WinBUGS |

### 制图原则

1. **分辨率**：至少 300dpi，确保打印清晰
2. **字体**：中文用宋体，英文用 Times New Roman
3. **配色**：使用协调的配色方案，避免过多颜色
4. **坐标轴**：标注清楚轴标题和单位
5. **图例**：放在图内合适位置，不遮挡数据
6. **一致性**：同类图表风格保持统一
