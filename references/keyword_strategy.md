# 数模优秀论文关键词策略

## 一、关键词基本规范

| 属性 | 规范 |
|------|------|
| 数量 | 4-5 个（推荐 5 个） |
| 排列顺序 | 核心方法 → 辅助方法 → 评价/验证手段 → 应用领域 |
| 分隔符 | 空格 或 分号 或 逗号（统一即可） |
| 长度 | 每个 2-8 个字 |
| 语言 | 中文为主，算法英文名可保留（如 LSTM、PSO、NSGA-II） |

---

## 二、关键词选取策略

### 核心原则：覆盖论文中使用的主要方法，兼顾层次性

一篇论文的关键词应像"方法全家福"，覆盖从数据预处理到最终验证的完整方法链。

### 选取层次模型

```
第1层：核心建模方法（论文最主要的1-2个模型/算法）
第2层：辅助分析方法（建模过程中使用的重要辅助方法）
第3层：求解/优化手段（求解模型使用的算法或软件）
第4层：验证/评价手段（用于验证或评价模型的方法）
```

### 优先级排序
1. 论文标题中出现的方法（必选）
2. 摘要中反复出现的方法名（优先）
3. 求解使用的特色算法（重要）
4. 数据预处理或评价方法（补充）

## 五、关键词避坑指南

### 常见错误

1. **过于宽泛**：如"数学模型""优化""数据分析"——太泛，无法体现特色
2. **过于具体**：如"MATLAB R2020a中的fmincon函数"——太细，属于实现细节
3. **重复冗余**：如同时写"优化"和"优化模型"
4. **遗漏核心**：标题中明确提到的核心方法未出现在关键词中
5. **数量过多/过少**：少于3个不够全面，多于6个失去聚焦

### 正确做法
- 关键词应能独立传达论文的方法特色
- 读者仅看关键词就能大致猜出论文用了什么方法
- 前2个关键词应与标题中的方法一致
